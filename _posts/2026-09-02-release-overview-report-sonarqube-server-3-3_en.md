The **3.3 version** of **Overview Report for SonarQube™ Server** is now available. Our plugin allows you to group different projects to get a better overview of the software quality status across your organization.

## What’s new in version 3.3?

Until now, the aggregated view of project groups mainly displayed information from the main branch. With version 3.3, we are introducing **branch support for Project Groups**, allowing you to select any specific branch directly from the *Overview Project Groups* interface.

Here’s where you can find the new branch selector in the interface:

<img width="90%" src="/img/sonarqube-overview/overview-report-sonarqube-server.png" alt="New branch selector">
<br>

*Select any branch to recalculate and display the aggregated metrics for the project group.*


## How to update to the new version?

* **If you use [Universal Plugin Manager for SonarQube Server™ (UPM)](https://marketplace.bitegarden.com/product/bitegardenUniversalPluginManager):**

The update is automatic and straightforward. Simply access your SonarQube instance’s administration panel and click the **Update** button. <br>

* **If you haven’t tried Overview Report for SonarQube™ Server yet:**

You can download a free trial version and install it on your server from our **[Marketplace](https://marketplace.bitegarden.com/product/bitegardenSonarQubeOverview)**. <br>

Ya está disponible la **versión 1.9** de nuestra **solución de seguridad** para SonarQube Cloud. La actualización del **Security Assessment for SonarQube Cloud** viene con un nuevo estándar de seguridad, al igual que hicimos para el Security Assessment for SonarQube Server: Cloud Application Security Assessment (CASA).

CASA (Cloud Application Security Assessment) toma como referencia el **OWASP Application Security Verification Standard (ASVS)**, uno de los estándares más utilizados para definir buenas prácticas y requisitos de seguridad en aplicaciones. Su objetivo es establecer **un marco común** que ayude a las organizaciones a identificar y aplicar medidas de seguridad de forma consistente, especialmente cuando una aplicación puede gestionar información sensible.

CASA permite utilizar un enfoque estructurado para evaluar el **nivel de protección de una aplicación y verificar** que cumple con los controles necesarios cuando se requiere una evaluación de seguridad formal.

<h2>What is PCI DSS?</h2>

PCI DSS (Payment Card Industry Data Security Standard) is a **global security standard** designed to protect sensitive information from **payment cardholders and reduce the risks** associated with the processing, storage, and transmission of financial data. Developed by the **Payment Card Industry Security Standards Council (PCI SSC)**, it establishes a set of technical and operational requirements that help organizations implement strong security controls, ensure the protection of payment account data, and maintain a secure environment against potential threats and vulnerabilities.

You can find more official information on the [PCI Security Standards](https://www.pcisecuritystandards.org/es/standards/pci-dss/) website.

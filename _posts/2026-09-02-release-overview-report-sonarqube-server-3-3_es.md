Ya está disponible la **versión 3.3** de **Overview Report for SonarQube™ Server**, nuestro plugin que permite agrupar distintos proyectos para mejorar la perspectiva del estado de calidad del software en tu organización.

## ¿Qué hay de nuevo en la versión 3.3?

Hasta ahora, la vista agregada de grupos de proyectos mostraba principalmente la información de la rama principal. En la versión 3.3, como novedad, añadimos el **soporte para ramas en Project Groups**, ya que ahora puedes elegir cualquier rama específica directamente desde la interfaz de *Overview Project Groups*.

A continuación, te mostramos dónde encontrar este nuevo selector de rama en la interfaz:

<img width="90%" src="/img/sonarqube-overview/overview-report-sonarqube-server.png" alt="Nuevo selector de ramas">
<br><br>
*Selecciona cualquier rama para recalcular y visualizar las métricas agregadas del grupo de proyectos.*


## ¿Cómo actualizar a la nueva versión?

* **Si utilizas [Universal Plugin Manager for SonarQube Server™ (UPM)](https://marketplace.bitegarden.com/product/bitegardenUniversalPluginManager):**  
  La actualización es automática y directa. Solo tienes que acceder al panel de administración de tu instancia de SonarQube y pulsar el botón **Actualizar**. <br>

* **Si aún no has probado Overview Report for SonarQube™ Server:**  
  Puedes descargar una versión de prueba gratuita e instalarla en tu servidor desde nuestro **[Marketplace](https://marketplace.bitegarden.com/product/bitegardenSonarQubeOverview)**. <br>

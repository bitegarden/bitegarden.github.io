The **version 1.9** of our **security solution** for SonarQube Cloud is now available. The latest update to **Security Assessment for SonarQube Cloud** introduces a new security standard, just as we did for Security Assessment for SonarQube Server: Cloud Application Security Assessment (CASA).

CASA (Cloud Application Security Assessment) is based on the **OWASP Application Security Verification Standard (ASVS)**, one of the most widely used standards for defining security best practices and requirements for applications. Its goal is to establish **a common framework** that helps organizations consistently identify and implement security measures, particularly when an application may handle sensitive information.

CASA provides a structured approach to assessing **an application's security level and verifying** that it meets the necessary controls when a formal security assessment is required.

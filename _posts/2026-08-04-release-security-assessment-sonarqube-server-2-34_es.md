<h2>¿Qué es el PCI DSS?</h2>

PCI DSS (Payment Card Industry Data Security Standard) es un **estándar global de seguridad** diseñado para proteger la información sensible de los titulares de **tarjetas de pago y reducir los riesgos** asociados al procesamiento, almacenamiento y transmisión de datos financieros. Desarrollado por el **Payment Card Industry Security Standards Council (PCI SSC)**, establece un conjunto de requisitos técnicos y operativos que ayudan a las organizaciones a implementar controles de seguridad sólidos, garantizar la protección de los datos de las cuentas de pago y mantener un entorno seguro frente a posibles amenazas y vulnerabilidades.

Puedes encontrar más información oficial en el sitio de [PCI Security Standards](https://www.pcisecuritystandards.org/es/standards/pci-dss/).
